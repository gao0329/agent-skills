# 固定输出规范

适用于本技能的每次交付，单主题、多主题及多轮检索均遵循此规范。主题、条数和任务根目录名称可以变化，内部结构、字段和收录条件保持一致。

## 目录

```text
<任务根目录>/
├── 文献清单.md
├── 文献索引.csv
└── 论文/
    └── <全文 PDF>
```

根目录只包含以上三项。`论文/` 只放最终通过验证的全文 PDF，一篇一份。候选题录、HTML、XML 和检查点放在系统临时区；发布时使用任务目录外的同盘暂存目录，校验后整体替换，完成即清理。临时数据不能出现在交付目录或项目历史。运行中断时可保留外部检查点供 `--resume` 使用。

## 收录与去重

- 只有成功获得、能正常解析、正文和文献身份通过检查的全文才能进入成功集合。
- 原版全文优先；原版不可用时才使用通过正文及内容支持检查的 XML 渲染全文。只有摘要的 XML 不收录，不能将摘要转成 PDF 补足成果。
- 按 PMID 去重，使用规范化 DOI 辅助合并重复记录。相同文献在多个主题中命中时合并检索来源，并保留一份 PDF；两种形式均可用时保留原版。
- 文献清单、CSV、最终回复及历史文献记录只使用该成功集合。失败候选不另设列表，不留逐篇历史。

## 文献清单.md

使用 UTF-8，首行直接为 `# 文献清单`，固定采用以下章节与顺序：

1. `研究范围`：用户研究范围，或未提供范围时的检索主题。
2. `检索记录`：检索日期、数据库、主题与实际执行的检索式。候选上限的含义为每个主题最多取回的候选数。
3. `全文汇总`：去重后的全文总数、原版 PDF 数、XML 渲染数。
4. `全文文献`：已获全文的统一表格，字段与 CSV 一致；文件链接指向相应 PDF。
5. `说明`：固定收录条件，以及实际发生的任务层面限制；没有额外限制时也保留该章节。

零全文时，汇总为 0，全文文献表格没有数据行，并写明“本次获得全文 0 篇”。不添加“仅摘要”“获取失败”“待补全文”等文献章节。

清单仅保留供人阅读的内容，不保存 JSON 注释、机器参数、哈希或隐藏的重复题录。检索记录中的主题、实际查询及候选上限使用可读文字表达，供理解范围与后续补充检索使用。

## 文献索引.csv

使用 UTF-8 BOM、标准 CSV 引号转义。固定字段及顺序：

```csv
获取状态,pmid,年份,期刊,标题,doi,文件,检索来源
```

| 字段 | 约束 |
|---|---|
| 获取状态 | 只允许 `全文(原版PDF)`、`全文(XML渲染)` |
| pmid | 本条全文所对应的 PMID，作为字符串保存 |
| 年份 | 发表年份；无法取得时为空 |
| 期刊 | 来源期刊，缺失时为空 |
| 标题 | 文献题名 |
| doi | DOI 标识符，缺失时为空；不填造出来的 DOI |
| 文件 | 相对任务根目录的 POSIX 路径，形如 `论文/<文件名>.pdf`，不能只写文件名或绝对路径 |
| 检索来源 | 命中的主题信息；多个来源用中文分号 `；` 连接，不能为每个来源重复创建一行 |

索引每条记录必须对应一个现存、通过验证的 PDF，不能存在空文件字段。零全文时只有上述表头。固定保持这八列，CSV 是持久化题录的唯一来源；不增加元数据旁挂文件、隐藏文件或额外列。

## PDF 命名

```text
[原版全文]_<PMID>_<年份>_<标题>.pdf
[全文]_<PMID>_<年份>_<标题>.pdf
```

标题使用脚本统一的文件名清洗规则，移除系统不支持的字符、合并空白并截断至 60 字符；文件名年份缺失时使用 `0000`。文件名前缀与 CSV 获取状态一致，不使用 `[摘要]` 前缀。

## 交付校验与恢复

- 成功集合条数 = 清单全文数据行数 = CSV 数据行数 = `论文/` 内去重后的 PDF 数。
- 每条相对路径必须位于本任务的 `论文/`，无多余文件、缺失文件或重复文献。
- 以 CSV 恢复题录，重新验证当前 PDF 的身份与正文，并核对 MD 表格中的题录、状态、来源、文件链接及汇总计数。最终回复和项目历史记录仅引用这些成功文献。
- 不将整篇 MD 与脚本模板逐字比较，不要求当前 PDF 与历史 SHA 摘要值保持一致；可读内容的修改不应仅因措辞或排版变化而校验失败。
- 兼容跳过旧清单首行的机器注释，但不依赖其中的 JSON；新生成清单不再写入该注释。
- 未完成任务的 `--resume` 必须使用同一任务的外部临时检查点，严格核对主题、候选上限、研究范围和输出路径等完整参数，并重新验证已有 PDF；不能盲信旧成功标记。中间状态只保存在该检查点中，正常完成后清除。
- 已完成任务的 `--resume` 检查当前三项产物，验证通过后直接返回，不重新检索。由于外部检查点已清除，不再比较旧任务参数；不能将这一行为描述为对旧参数的严格匹配。
- 补充检索从 CSV 恢复成功题录，并从 MD 的可读检索记录读取原查询；不得为此恢复机器注释或新增元数据文件。
- 发现既有非空目录含旧版或额外产物时拒绝混写；使用新任务目录。既有产物和历史记录的清理迁移另行处理，不由下载流程自动删除。
